# Acknowledgements / 致谢

LinuxHub is built on and interoperates with open-source software from the Android and Linux ecosystems. LinuxHub 使用并与 Android、Linux 开源生态中的多个项目协作。

## Open-source ecosystem / 开源生态

| Project / 项目 | Role / 用途 |
| --- | --- |
| [Android Open Source Project](https://source.android.com/) | Android application platform and system APIs / Android 应用平台与系统 API |
| [Ubuntu](https://ubuntu.com/) | ARM64 Linux userspace / ARM64 Linux 用户空间 |
| [XFCE](https://www.xfce.org/) | Desktop environment and desktop components / 桌面环境与桌面组件 |
| [Termux](https://github.com/termux) | Terminal and Android integration foundations / 终端与 Android 集成基础 |
| [Termux:X11](https://github.com/termux/termux-x11) | X11 display runtime / X11 显示运行时 |
| [PRoot](https://proot-me.github.io/) | Userspace Linux execution layer / Linux 用户空间运行层 |
| [Shizuku](https://github.com/RikkaApps/Shizuku) | User-authorized Android privileged bridge / 用户授权的 Android 特权桥 |
| [Mesa](https://www.mesa3d.org/) | Graphics driver stack / 图形驱动栈 |
| [PulseAudio](https://www.freedesktop.org/wiki/Software/PulseAudio/) | Audio services / 音频服务 |
| [Kotlin](https://kotlinlang.org/) | Android application development / Android 应用开发 |
| [Jetpack Compose](https://developer.android.com/compose) | Android user interface / Android 用户界面 |
| [Gradle](https://gradle.org/) | Build system / 构建系统 |
