# Acknowledgements / 致谢

LinuxHub is built on and interoperates with open-source software from the Android and Linux ecosystems. LinuxHub 使用并与 Android、Linux 开源生态中的多个项目协作。

## Open-source ecosystem / 开源生态

| Project / 项目 | Role / 用途 |
| --- | --- |
| [Android Open Source Project](https://source.android.com/) | Android application platform and system APIs / Android 应用平台与系统 API |
| [Ubuntu](https://ubuntu.com/) | ARM64 Linux user space and Ubuntu packages / ARM64 Linux 用户空间与 Ubuntu 软件包 |
| [GNOME](https://www.gnome.org/) | GNOME Shell, desktop components, and applications / GNOME Shell、桌面组件与应用 |
| [Mutter](https://gitlab.gnome.org/GNOME/mutter) | GNOME X11 compositor and window manager / GNOME X11 合成器与窗口管理 |
| [GJS](https://gitlab.gnome.org/GNOME/gjs) | GNOME Shell JavaScript runtime / GNOME Shell JavaScript 运行时 |
| [DING](https://gitlab.gnome.org/GNOME/nautilus) | Desktop icon and file interaction extension / 桌面图标与文件交互扩展 |
| [Termux](https://github.com/termux) | Terminal and Android integration foundations / 终端与 Android 集成基础 |
| [Termux:X11](https://github.com/termux/termux-x11) | X11 display runtime foundations / X11 显示运行时基础 |
| [Lorie](https://github.com/termux/termux-x11) | LinuxHub X11 presentation and input runtime / LinuxHub X11 显示与输入运行时 |
| [PRoot](https://proot-me.github.io/) | User-space Linux execution and syscall compatibility / Linux 用户空间执行与系统调用兼容 |
| [Mesa](https://www.mesa3d.org/) | OpenGL, Vulkan, Zink, llvmpipe, and VirGL integration / OpenGL、Vulkan、Zink、llvmpipe 与 VirGL 集成 |
| [PulseAudio](https://www.freedesktop.org/wiki/Software/PulseAudio/) | Ubuntu audio services and the FIFO output bridge / Ubuntu 音频服务与 FIFO 输出桥 |
| [Rust](https://www.rust-lang.org/) | Session controller and getifaddrs bridge / 会话控制与 getifaddrs 桥 |
| [OpenSSL](https://www.openssl.org/) | HTTPS and certificate support / HTTPS 与证书支持 |
| [Kotlin](https://kotlinlang.org/) | Android application development / Android 应用开发 |
| [Jetpack Compose](https://developer.android.com/compose) | Android user interface / Android 用户界面 |
| [Gradle](https://gradle.org/) | Build system / 构建系统 |

LinuxHub also interoperates with Chrome, LibreOffice, Thunderbird, Nautilus, GNOME Terminal, Evince, Remmina, Transmission, Rhythmbox, Totem, Shotwell, and other packages distributed by Ubuntu. Their copyright and license terms remain with their respective projects.

LinuxHub 还与 Ubuntu 分发的 Chrome、LibreOffice、Thunderbird、Nautilus、GNOME Terminal、Evince、Remmina、Transmission、Rhythmbox、Totem、Shotwell 等软件协作。相关版权和许可证仍归各自项目所有。
